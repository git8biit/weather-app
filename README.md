Приложение "weather app"

Веб-приложение для просмотра текущих метеорологических данных по географическим координатам.
Для получения данных о погоде используется бесплатный API Open-Meteo, а для отображения локации на карте — встроенный iframe OpenStreetMap.

Рабочая версия приложения доступна по адресу: https://git8biit.github.io/weather-app/

Реализованные функции:
Модуль validation.js — отвечает за проверку пользовательского ввода.
parseCoordinate(raw, min, max) — убирает пробелы, заменяет запятую на точку, проверяет, что введено число и что оно попадает в допустимый диапазон.
validateForm(latitudeRaw, longitudeRaw) — вызывает parseCoordinate для широты и долготы последовательно.

Модуль api.js — отвечает за взаимодействие с внешним API.
fetchWeather(coordinates) — формирует URL с параметрами запроса, выполняет fetch к Open-Meteo, проверяет статус ответа и возвращает нормализованные данные.
normalizeWeather(data, coordinates) — извлекает из ответа API нужные поля, округляет температуры и собирает их в единый объект.

Модуль weather-codes.js — справочник кодов погоды.
describeWeather(code) — по числовому WMO-коду возвращает объект с текстовым описанием на русском языке и соответствующей иконкой.

Модуль map.js — формирование ссылки на карту.
buildMapUrl({ latitude, longitude }) — вычисляет границы области вокруг точки и возвращает URL для iframe OpenStreetMap с маркером в центре.

Модуль widget.js — логика отдельного виджета погоды.
createWidget(container) — клонирует HTML-шаблон из тега template, добавляет его в контейнер на странице и навешивает обработчик клика на кнопку.
handleWeatherRequest(widget) — читает координаты, вызывает валидацию, блокирует кнопку, делает запрос к API и отрисовывает результат.
renderWeather(widget, weather) — заполняет элементы виджета даннымиы.
renderDetails(list, weather) — формирует HTML-список с дополнительной информацией.
readCoordinates(widget) — вспомогательная функция, считывает текущие значения из полей ввода виджета и возвращает их в виде объекта.
showError(widget, message) — выводит текст ошибки в специально отведённый элемент и делает его видимым.
hideError(widget) — скрывает элемент с ошибкой, если он был показан ранее.

Модуль app.js — точка входа в приложение.
init() — находит контейнер для виджетов и кнопку добавления, создаёт первый виджет при загрузке страницы и регистрирует обработчик для создания новых виджетов по клику.

Запуск локально:
Из-за использования ES-модулей для локального тестирования требуется HTTP-сервер. Самый простой способ — запустить встроенный сервер Python командой:
py -m http.server 8000
После этого приложение будет доступно в браузере по адресу http://localhost:8000.
